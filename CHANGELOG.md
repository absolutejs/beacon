## 0.7.0-beta.13 — 2026-09-30

### Fixed

- **Do not report a service worker as a failed installation when a newer release replaced it: one that finished installing and then waited, or one cut off mid-install by a newer worker. A worker that fails its own install still reports.** (`createBeacon`, `BEACON_SDK_VERSION`)

## 0.7.0-beta.12 — 2026-09-27

### Fixed

- **Stop TBT observation after its measurement window and clean up on close; ignore late vital delivery.** (`createBeacon`, `BEACON_SDK_VERSION`)

## 0.7.0-beta.11 — 2026-09-27

### Fixed

- **Do not promote presentation-only Event Timing waits when every overlapping animation frame explicitly reports zero blocking and no scripts. Preserve incidents with positive blocking, script activity, missing attribution, long handlers or meaningful input delay; Web Vitals collection is unchanged.** (`createBeacon`, `BEACON_SDK_VERSION`)

## 0.7.0-beta.10 — 2026-09-27

### Fixed

- **Ignore wheel events cancelled by later handlers when detecting scroll jail, and capture bounded scroll geometry, overflow policy, direction and modal ownership for genuine immobility without changing issue grouping.** (`createBeacon`, `BEACON_SDK_VERSION`)

## 0.7.0-beta.9 — 2026-09-27

### Fixed

- **Exclude known 1Password notification covers and retain request origins in network-failure diagnostics without credentials or query strings. Same-origin grouping remains stable across environments. Keep layout pixel measurements out of fingerprints and include geometry and sticky/fixed ancestor context in collision and occlusion reports. Read only browser-exposed XHR response headers to avoid unsafe-header console errors while preserving available trace correlation.** (`createBeacon`, `BeaconNetworkFailure`, `BEACON_SDK_VERSION`)
